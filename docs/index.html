Use your logged-in ChatGPT, Gemini and DeepSeek sessions inside OpenCode.

An open-source plugin that registers your browser-authenticated web sessions as OpenCode models. No API key, no per-token billing. Checksum-verified binaries and fail-closed recovery that never re-submits a prompt.

Engines

All advertise tool calling. Pick the one whose subscription you already hold.

ChatGPT Web

CDPprojectsrecovery UX

Full feature set: projects per session, thread reuse, media inputs. Needs Chrome and a dedicated profile.

Gemini Web

CDPtext-onlylocal build

Text-only browser engine. Build locally, no published release. Own tab, profile and CDP port.

DeepSeek Web

HTTP+SSEno browser

Speaks the web API directly. No Chrome, no CDP. Needs a userToken from a signed-in session.

Install

Prerequisites: Node.js 20+, OpenCode v1 or v2, Bun 1.1+, Chrome or Chromium.

1

Run the installer

$ npx @bojackduy/opencode-web-bridges install

2

Restart OpenCode

Select chatgpt-web/chatgpt-web in /models.

3

Log in once

Run /chatgpt-login, sign in to ChatGPT in the profile window, then /chatgpt-status.

$ npx @bojackduy/opencode-web-bridges install --host v2 --dry-run

Dry-run previews exact config and required release assets without writing.

FAQ

Does this bypass ChatGPT, Gemini or DeepSeek limits?

No. It uses your own logged-in session, subject to your account's access and usage limits and terms of service.

Where do my credentials and prompts go?

Nowhere third-party. The bridge runs on 127.0.0.1 and drives your own Chrome profile. Logs are content-free: sizes, counts and reason codes only.

What happens if a turn is interrupted?

Recovery reads the remote transcript back. Nothing is re-submitted. Fail-closed on uncertainty, so a dropped request can never double-spend a prompt.

Does it work with OpenCode v1 and v2?

Yes. One package covers both hosts via a server hook (v1) or setup domains (v2).

Is it free?

Yes, open source under AGPL-3.0. You still need your own ChatGPT Plus/Pro, Gemini or DeepSeek subscription.
