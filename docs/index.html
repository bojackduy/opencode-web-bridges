Keep the connection local.

Bridge services run on your machine. Check each engine’s setup guide.

Get it running.

Install the plugin, restart OpenCode, then sign in to your web session.

Terminal · local machine
$ npx @bojackduy/opencode-web-bridges install

Restart OpenCode when installation finishes.
Select a web bridge from /models.
Complete sign-in when prompted.

$ npx @bojackduy/opencode-web-bridges install --help

Before you connect.

Quick answers about your web sessions.

Do I need an API key?

No. Sign in to an eligible account.

Does this bypass provider limits?

No. Provider account limits and terms still apply.

Follow the GitHub setup guide, or open an issue.
