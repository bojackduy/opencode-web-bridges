The problem

OpenCode models need provider API keys and paid per-token billing. You already pay for ChatGPT Plus/Pro or a Gemini subscription — using it inside OpenCode shouldn't mean paying twice.

Cost

Double paying

Subscription plus API billing for the same model family.

Friction

Manual wiring

Provider and MCP entries hand-edited, easy to break.

Reliability

Lost turns

Interrupted browser turns leave uncertain state; retries re-submit.

What it does

Bridges your logged-in web sessions into OpenCode as ordinary models, with recovery that fails closed.

No API key

Your own session

Uses the Chrome profile you log into once. Subject to your account's own limits.

Install

One command

Detects OpenCode v1/v2, downloads checksum-verified binaries, writes config without clobbering.

Recovery

Fail-closed

Exact/key/window bubble identity, dirty adopt-first, hash-lineage auto-resync. Never re-submits on retry.

Hosts

v1 + v2

One package covers both OpenCode generations via server hook or setup domains.

Privacy

Content-free logs

Sizes, counts, reason codes only. No prompt text or args in logs.

Engines

Three providers

ChatGPT, Gemini, DeepSeek — pick the one whose subscription you hold.

Engines

All advertise tool calling. Choose by the subscription you already hold.

ChatGPT Web

primaryCDPprojects

Full feature set: projects per session, thread reuse, recovery UX, media inputs. Needs Chrome + dedicated profile.

Gemini Web

CDPtext-only

Text-only browser engine. Local build required (no published release). Own tab, profile and CDP port.

DeepSeek Web

HTTP+SSEno browser

Speaks the web API directly. No Chrome, no CDP. Needs a userToken from a signed-in session.

Install

Prerequisites: Node.js ≥20, OpenCode v1 or v2, Bun ≥1.1, Chrome/Chromium.

1

Run the installer

npx @bojackduy/opencode-web-bridges install

2

Restart OpenCode

Select chatgpt-web/chatgpt-web in /models.

3

Log in once

Run /chatgpt-login, sign in to ChatGPT in the profile window, then /chatgpt-status.

$ npx @bojackduy/opencode-web-bridges install --host v2 --dry-run

Dry-run previews exact config and required release assets without writing.

FAQ

Does this bypass ChatGPT/Gemini usage limits?

No. It uses your own logged-in session, subject to your account's access and usage limits.

Is my data sent to a third party?

No. The bridge runs locally on 127.0.0.1 and drives your own Chrome profile. Logs are content-free.

Why AGPL-3.0?

Copyleft ensures improvements stay open, including for network use. See LICENSE.

Can I use it with OpenCode v1 and v2?

Yes — one package, both hosts, via server hook (v1) or setup domains (v2).

What if a turn is interrupted?

Recovery reads the remote transcript back; nothing is re-submitted. Fail-closed on uncertainty.
